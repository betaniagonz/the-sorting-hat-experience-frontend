## 1. 23 de Febrero, 2025

**Prompt:**

> Contexto del Rol:
> Actúa como un Desarrollador Full-Stack Senior experto en SolidJS y Java Spring Boot. Vamos a construir un minijuego titulado "Harry Potter: The Sorting Hat Experience".
>
> Stack Tecnológico:
> Frontend: SolidJS (usando Signals para el estado), Tailwind CSS para estilos.
> Backend: Java 17+ con Spring Boot.
> Base de Datos: Oracle DB (JPA/Hibernate).
>
> Identidad Visual (Estilo Mapa del Merodeador):
> Paleta: Fondo color pergamino viejo (#f4e4bc), texto en tinta sepia o negra desgastada.
> UI: Bordes que parezcan dibujados a mano, animaciones de "tinta extendiéndose" y fuentes tipo caligrafía/pluma (usa Google Fonts como 'Dancing Script' o 'Henny Penny' si no hay una específica).
> Componentes: Los botones deben parecer sellos de cera o etiquetas de papel pegadas.
>
> Funcionalidades Clave:
> El Test del Sombrero Seleccionador:
> Cuestionario dinámico (un JSON de preguntas). Cada respuesta suma puntos a una de las 4 casas (Gryffindor, Hyllepuff, Ravenclaw, Slytherin).
> Al terminar, debe enviar los datos del estudiante y la casa asignada al backend para persistirlos en Oracle DB.
>
> La Carta de Aceptación:
> Tras la asignación, muestra un Modal Animado que se despliega como un sobre de Hogwarts.
> Contenido: "Estimado/a [Nombre], nos complace informarle que ha sido aceptado en la casa de [Casa]...". Debe incluir un botón para "Ir al Callejón Diagon".
>
> Feature Extra: Ollivander's Store:
> Bloqueado hasta que el usuario tenga una casa.
> Lógica de Varitas: Implementa una función que filtre varitas compatibles. Ejemplo:
> Gryffindor: Madera de Roble, núcleo de Nervio de Dragón.
> Slytherin: Madera de Tejo, núcleo de Pluma de Fénix.
> Ravenclaw: Madera de Ébano, núcleo de Pelo de Unicornio.
> Permite al usuario "elegir" (o que la varita lo elija a él) y actualizar su registro en la DB.
>
> Realiza un plan de desarrollo primero antes de iniciar el desarrollo.
> todo el plan agregalo a la carpeta @documents_AI
